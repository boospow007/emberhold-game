# เพิ่ม CLAUDE.md และโฟลเดอร์ doc

- วันที่: 2026-09-08
- ผู้แก้ไข: Claude Code
- ไฟล์ที่เกี่ยวข้อง: `CLAUDE.md`, `doc/README.md`, `doc/2026-09-08-claude-md.md`

## สิ่งที่เปลี่ยน

1. สร้าง `CLAUDE.md` ที่ root ของโปรเจกต์ เป็นคู่มือสำหรับ Claude Code รุ่นถัดไป ประกอบด้วย
   - คำสั่งที่ใช้บ่อย (dev, build, typecheck, lint, format, db:generate, การรันเทสต์ทั้งชุดและทีละเคส)
   - โครงสร้างสถาปัตยกรรม 3 ชั้น: engine (pure simulation), scene (Three.js render), API route (D1)
   - โมเดล co-op แบบ host-authoritative ผ่าน HTTP polling และกฎ seq/acks ที่ทำให้ command ถูกประมวลผลครั้งเดียว
   - หมายเหตุเรื่อง deployment บน OpenAI Sites ผ่าน vinext
2. สร้างโฟลเดอร์ `doc/` พร้อม `README.md` ที่กำหนดรูปแบบเอกสารและตารางดัชนี
3. เพิ่มหัวข้อ "Documentation rule" ใน `CLAUDE.md` บังคับให้ทุกการแก้ไขโค้ดต้องมีไฟล์ใน `doc/`

## เหตุผล

ผู้ใช้ต้องการให้ทุกการแก้ไขมีเอกสารประกอบ เพื่อให้ย้อนดูได้ว่าเปลี่ยนอะไร ทำไม และทดสอบอย่างไร โดยไม่ต้องอ่าน git diff

## ผลกระทบ / สิ่งที่ต้องทำต่อ

- ไม่มีผลต่อโค้ดหรือพฤติกรรมของเกม
- ยังไม่ได้ยืนยันคำสั่งสำหรับ apply migration ลง D1 ในเครื่อง เนื่องจากไม่มี `wrangler.toml` ที่ root และ README ไม่ได้ระบุคำสั่ง ควรเติมเมื่อทราบขั้นตอนที่แน่นอน
