## สิ่งที่เปลี่ยน

### Engine (`lib/game/engine.ts`)
1. **ทรัพยากร 5 ชนิด** `World.gold` ถูกแทนด้วย `World.res = { gold, wood, stone, iron, food }` เริ่มต้น ทอง 60 ไม้ 60 อาหาร 20 มีฟังก์ชัน `canAfford`, `pay`, `missing`, `costText` และชนิด `Cost`
2. **ภูมิประเทศอยู่ใน World** `World.terrain` เก็บต้นไม้ หิน และสายแร่ (`ore`) พร้อม `terrainVersion` สำหรับ cache ของ pathfinding ต้นไม้มีไม้ 30 หน่วย หินทุกก้อนที่ 3 เป็นสายแร่
3. **ตัดไม้ด้วยตัวเอง** ฮีโร่ที่ยืนติดต้นไม้และไม่มีศัตรูในระยะจะตัดอัตโนมัติ +5 ไม้ทุก 0.9 วินาที ต้นไม้หายเมื่อไม้หมด (`Player.task = 'chop'`)
4. **คนงาน** `workerCap` = ฐานแม่ (3/5/7/9 ตามระดับ) + บ้าน (2/5/10 ตามระดับ) `workersUsed` = ผลรวมของสิ่งก่อสร้างป้องกัน ถ้าใช้เกิน (บ้านถูกทำลาย) ป้อมยิงช้าลง 1.75 เท่า
5. **ระดับฐานแม่ 1–4** อัปเกรดด้วยคำสั่ง `upgrade` id `keep` ต้องยืนใกล้ ราคา L2 ไม้ 60 หิน 30, L3 หิน 60 เหล็ก 30, L4 เหล็ก 60 ทอง 200 แต่ละระดับ +500 HP, ขยายรัศมีก่อสร้าง 11/15/19/23 และเป็นเพดานระดับของสิ่งก่อสร้างอื่น (อาคาร L2 ต้องฐาน L2)
6. **สิ่งก่อสร้าง 11 ชนิด** เพิ่ม บ้านคนงาน, ไร่นา (เดิมคือโรงสี ตอนนี้ให้อาหาร), โรงเลื่อย, เหมืองทอง, เหมืองหิน, เหมืองเหล็ก, บัลลิสตา แต่ละชนิดมี `tier`, `workers`, `node` (ต้องวางบนหินหรือสายแร่ แล้วแทนที่ก้อนนั้น) และ `upgrades` ราคาเฉพาะ
7. **รายได้จ่ายตอนจบวัน** `income(w)`: ทอง 20 + เหมืองทอง 20/ระดับ, อาหาร 10/ระดับจากไร่, หิน 12/ระดับ, เหล็ก 8/ระดับ, ไม้จากโรงเลื่อย 4 ต่อต้นในรัศมี 6 (สูงสุด 3 ต้น) ต่อระดับ
8. **ถอด timer อัตโนมัติของ prep** วันใหม่เริ่มเมื่อผู้เล่นกดเท่านั้น ตามข้อกำหนด "1 วัน = 1 wave กดเริ่มเอง"
9. ฟังก์ชันตรวจสอบสำหรับ UI: `buildGate` (ปลดล็อก/ระดับ/ทรัพยากร/คนงาน), `buildError` (รวมตำแหน่ง), `upgradeError`, `upgradeCost`, `branches`

### Scene (`lib/game/scene.ts`)
- ภูมิประเทศ sync จาก `w.terrain` ทุกเฟรม ต้นไม้ที่ถูกตัดหดลงและหายไป สายแร่มีจุดสีทอง
- โมเดลใหม่: บ้าน (ขยายตามระดับ), โรงเลื่อย (ใบเลื่อยหมุน), เหมือง 3 แบบ, บัลลิสตา, กำแพงหินเมื่อ L2+, ฐานแม่ขยายตามระดับ
- เอฟเฟกต์ `chop` และ `bolt`

### UI (`app/Game.tsx`, `app/globals.css`)
- แถบทรัพยากรบรรทัดเดียว 5 ชนิด + คนงาน `ใช้/ทั้งหมด` (แดงเมื่อเกิน) และป้ายระดับฐานแม่
- เลข "วันที่" แทน WAVE, ข้อความ prep บอกว่ากดเริ่มเมื่อพร้อม, ปุ่ม "เริ่มวัน"
- เมนูสร้าง 3 หมวด (ป้องกัน / เศรษฐกิจ / ที่พัก) แสดงราคาหลายชนิดเป็น chip (แดงเมื่อไม่พอ), จำนวนคนงาน, ป้ายระดับฐานที่ต้องการ และเหตุผลที่กดไม่ได้
- แถบวางสิ่งก่อสร้างแสดงเหตุผลที่วางไม่ได้แบบเรียลไทม์ (ไกลเกิน, ต้องวางบนหิน ฯลฯ)
- ปุ่ม "ฐานแม่" เมื่อยืนใกล้ เปิดแผงอัปเกรดฐานแม่ แผงอัปเกรดอาคารใช้สายอัปเกรดจาก engine (rapid/heavy หรือ grow)
- ตัวบ่งชี้ "กำลังตัดไม้" ในแถบสถานะฮีโร่
- **แก้บั๊กเดิม**: แผง `.game-sheet` เลื่อนหลุดจอเพราะ Tailwind v4 ใส่ `translate: -50% -50%` ซ้อนกับ `transform` ของเรา เพิ่ม `translate: none`

## ผลกระทบ / สิ่งที่ต้องทำต่อ
- **ไม่มีการเปลี่ยน schema D1 หรือ API** snapshot ใหญ่ขึ้นเล็กน้อยจาก `terrain` (65 รายการ)
- ตัวเลขทั้งหมดเป็นค่าตั้งต้น ยังไม่ได้ playtest สมดุล โดยเฉพาะ: ไม้เริ่มต้น 60 พอสำหรับป้อม 2 หลังเท่านั้น ผู้เล่นต้องตัดไม้ตั้งแต่วันแรก
- ยังไม่มี: หน่วยทหาร (เฟส 3), บ้านวิจัย, ตลาด, โกดัง, กับดัก, Wonder (ตามแคตตาล็อกใน game-doc ข้อ 6)
- ศัตรูยังไม่เล็งบ้านเป็นพิเศษ (infection แบบเบายังไม่ทำ)
- โรงเลื่อยนับต้นไม้ในรัศมี แต่ไม่ได้ลดไม้ในต้น (ต้นไม้ไม่หมดจากโรงเลื่อย) ตั้งใจให้เป็นรายได้ถาวรแบบเบา
- การทดสอบในเบราว์เซอร์ทำได้เฉพาะ HUD และเมนู (pane ของเบราว์เซอร์ถูกซ่อนทำให้ simulation หยุด) การเดินและตัดไม้ยืนยันด้วยเทสต์ engine
