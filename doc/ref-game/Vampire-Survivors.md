# Vampire Survivors — เอกสารทำความเข้าใจเกมเพื่อใช้อ้างอิง

- ผู้พัฒนา: poncle (Luca Galante เริ่มทำคนเดียว) สหราชอาณาจักร
- ออก Early Access บน Steam: ธันวาคม 2021 · เวอร์ชัน 1.0: ตุลาคม 2022
- แพลตฟอร์ม: PC, มือถือ iOS/Android (ฟรีมีโฆษณา, ธันวาคม 2022), Switch, Xbox, PlayStation
- แนวเกม: Roguelite auto-shooter / "bullet heaven" มุมมองบน 2D pixel art
- จุดขาย: ควบคุมแค่การเดิน โจมตีอัตโนมัติทั้งหมด รอบละ 30 นาที ราคาถูกมาก ติดงอมแงม
- อิทธิพล: ต้นแบบของแนว "Survivors-like" ที่มีเกมตามมาหลายร้อยเกม (Brotato, 20 Minutes Till Dawn, HoloCure ฯลฯ) และเป็นต้นแบบตรงของ Emberhold ในเรื่อง "เดินอย่างเดียว โจมตีเอง"

> จุดประสงค์ของเอกสารนี้คือถอดแก่นของเกมมาเป็นข้อมูลอ้างอิงสำหรับออกแบบ Emberhold ไม่ใช่คู่มือเล่นเกม

---

## 1. Core loop

```
เลือกตัวละคร + ด่าน → เดินหลบฝูงศัตรู → อาวุธยิงเอง → เก็บ XP gem → level up เลือก 1 ใน 3–4
→ ศัตรูหนาแน่นขึ้นทุกนาที → boss ทุกช่วงเวลา → กล่องสมบัติ → อาวุธวิวัฒนาการ
→ นาทีที่ 30 "Death" มาเก็บ → จบรอบ → เอาทองไปซื้ออัปเกรดถาวร → ปลดล็อกของใหม่ → เล่นอีกรอบ
```

ในรอบเดียว (run) ผู้เล่นทำได้แค่ **เดิน** ทุกอย่างที่เหลือคือการตัดสินใจตอน level-up ส่วน meta-loop นอกรอบคือร้านค้าอัปเกรดถาวรและระบบปลดล็อก

## 2. โครงสร้างของหนึ่งรอบ (30 นาที)

| ช่วงเวลา   | สิ่งที่เกิดขึ้น                                                              |
| ---------- | ---------------------------------------------------------------------------- |
| 0–5 นาที   | ศัตรูน้อย ผู้เล่นอ่อน เลือก build ทิศทางแรก                                  |
| 5–15 นาที  | ฝูงหนาขึ้นเรื่อยๆ mini-boss ทุกๆ ไม่กี่นาที เริ่มมีอาวุธ max level           |
| 15–25 นาที | อาวุธเริ่มวิวัฒนาการ จอเต็มไปด้วยเอฟเฟกต์ ผู้เล่นแทบอมตะ (power fantasy)     |
| 25–30 นาที | ฝูงหนาสุด "wall of enemies" ทดสอบว่า build แน่นพอไหม                         |
| 30:00      | **Death (Reaper)** ปรากฏ ฆ่าไม่ได้ (เกือบ) มาเก็บผู้เล่น จบรอบด้วยการตายเสมอ |

ด่านมี **timeline ที่ตายตัว**: นาทีไหนสปอว์นศัตรูชนิดใด boss มาเมื่อไร ผู้เล่นเรียนรู้และวางแผนได้ แต่ RNG มาจากตัวเลือกตอน level-up

## 3. ระบบอาวุธและไอเทม

- ช่องอาวุธ **6 ช่อง** + ช่องไอเทมพาสซีฟ **6 ช่อง**
- อาวุธแต่ละชิ้นมี level สูงสุด 8 พาสซีฟส่วนใหญ่ level 5
- **Evolution**: อาวุธ max level + พาสซีฟคู่ของมัน แล้วเปิด **กล่องสมบัติ** (ดรอปจาก boss) จะรวมเป็นอาวุธขั้นสูง เช่น
  - Whip + Hollow Heart → Bloody Tear
  - Magic Wand + Empty Tome → Holy Wand
  - Garlic + Pummarola → Soul Eater
  - King Bible + Spellbinder → Unholy Vespers
  - Peachone + Ebony Wings → Vandalier (union ของอาวุธ 2 ชิ้น)
- **Union**: อาวุธ 2 ชิ้นรวมกันเป็นชิ้นเดียว คืนช่องว่างให้ 1 ช่อง
- **Limit Break**: หลังทุกอย่าง max แล้ว level-up ต่อจะบวกสถิติเข้าอาวุธที่มี ทำให้ scaling ไม่หยุด
- ตัวเลือก level-up มี **น้ำหนักตามที่ถืออยู่แล้ว** ของที่มีอยู่จะออกบ่อยกว่า ทำให้ build มีความสม่ำเสมอ
- Reroll / Skip / Banish จำนวนจำกัดต่อรอบ (ซื้อเพิ่มจากร้านถาวร) ให้ผู้เล่นควบคุม RNG ได้บ้าง

## 4. สถิติที่สำคัญ

| สถิติ    | ผล                                                    |
| -------- | ----------------------------------------------------- |
| Might    | ดาเมจ                                                 |
| Cooldown | ยิงถี่ขึ้น                                            |
| Area     | ขนาดเอฟเฟกต์                                          |
| Speed    | ความเร็วกระสุน                                        |
| Duration | อยู่นานขึ้น                                           |
| Amount   | จำนวนกระสุนเพิ่ม                                      |
| Magnet   | รัศมีดูด gem                                          |
| Luck     | โอกาสดรอปและตัวเลือกดีขึ้น                            |
| Growth   | XP ที่ได้                                             |
| Greed    | ทองที่ได้                                             |
| Curse    | เพิ่มความยาก (ศัตรูมากขึ้น เร็วขึ้น) แต่ได้ของมากขึ้น |
| Revival  | ฟื้นหลังตาย                                           |

**Curse** เป็นตัวอย่างดีของ "ความยากที่ผู้เล่นเลือกเอง" แลกกับ reward

## 5. ศัตรูและ boss

- ศัตรูส่วนใหญ่โง่มาก เดินตรงเข้าหาผู้เล่น ความยากมาจาก **จำนวน** ไม่ใช่ความฉลาด
- ชนิดพิเศษ: ค้างคาวฝูงพุ่งเป็นแนว, ผีทะลุกำแพงศัตรู, ต้นไม้/ประตูอยู่กับที่ยิงระยะไกล, Elite ที่ต้องฆ่าเพื่อรับกล่อง
- Boss ตามเวลา ดรอปกล่องสมบัติเสมอ กล่องอาจให้ของ 1, 3 หรือ 5 ชิ้น (jackpot ที่มีเสียงตู้สล็อต)
- นาทีท้ายๆ มี "กำแพงศัตรู" วิ่งเข้ามาจากขอบจอเป็นแถบยาว บังคับให้ผู้เล่นขยับ

## 6. Meta-progression (นอกรอบ)

- **ทอง** เก็บได้ในรอบ นำไปซื้อ **PowerUp ถาวร** (Might, Armor, Max HP, Recovery, Cooldown, ฯลฯ) ราคาเพิ่มขึ้นทุกครั้ง มีปุ่ม refund คืนทองทั้งหมด
- **ปลดล็อก** ตัวละคร อาวุธ ด่าน ผ่าน achievement ในเกม เช่น "ฆ่า 3,000 ตัวด้วยตัวละคร X" หรือ "อยู่รอด 10 นาทีในด่าน Y" ทุกรอบเปิดของใหม่เกือบเสมอ
- **Arcana**: การ์ดโบนัสระดับรอบ เลือกตอนเริ่มและได้เพิ่มระหว่างรอบ เปลี่ยนกฎอาวุธ (เช่น ให้กระสุนเด้ง) เป็นชั้นความหลากหลายที่เพิ่มหลังผู้เล่นเห็นทุกอย่างแล้ว
- **Hyper / Hurry / Inverse mode**: โหมดต่อด่านที่เร็วขึ้น ยากขึ้น ได้ทองมากขึ้น สำหรับผู้เล่นที่จบด่านแล้ว
- ตัวละครแต่ละตัวมีอาวุธเริ่มต้นและโบนัสเฉพาะ บางตัวเปลี่ยนกฎเกมทั้งรอบ (เช่น ไม่มีอาวุธ, ดาเมจโตตามเวลา)

## 7. กลไกที่ทำให้เกมนี้โดดเด่น

### 7.1 ลดการควบคุมเหลืออย่างเดียว

ผู้เล่นทำได้แค่เดิน ทำให้เล่นได้บนทุกอินพุต ทุกอายุ และเปิดพื้นที่ให้สมองไปคิดเรื่อง build แทน micro

### 7.2 Feedback loop ที่แน่นมาก

ทุก 10–20 วินาทีมี level-up ทุกฆ่ามี gem ทุก gem มีเสียง ตัวเลขดาเมจเด้ง จอเต็มไปด้วยเอฟเฟกต์ ทั้งหมดเป็น "dopamine drip" ที่ทำให้ "อีกรอบเดียว" เกิดขึ้นตลอด

### 7.3 Power curve แบบเบี่ยงเบนจากปกติ

เกมส่วนใหญ่ยากขึ้นเรื่อยๆ แต่ VS ทำให้ผู้เล่น **แข็งแกร่งเร็วกว่าที่ศัตรูแข็ง** ในช่วงกลาง แล้วบีบกลับช่วงท้าย ผลคือรู้สึกเป็นเทพ 10 นาทีต่อรอบ

### 7.4 จบรอบด้วยการตายเสมอ แต่ไม่รู้สึกแพ้

Death มาที่ 30:00 การตายคือ "จบ" ไม่ใช่ "แพ้" ผู้เล่นไม่ผิดหวังกับการตาย และทุกรอบให้ทองกับ achievement ไม่ว่าจะจบตอนไหน

### 7.5 ระบบปลดล็อกที่มองเห็นได้

มีหน้า Unlocks ที่บอกเงื่อนไขชัดเจน ผู้เล่นรู้ว่ารอบถัดไปจะได้อะไรถ้าทำอะไร กลายเป็นเป้าหมายระยะสั้นที่ต่อเนื่องหลายสิบชั่วโมง

### 7.6 XP gem ที่ต้องเดินไปเก็บ

การเก็บ gem บังคับให้ผู้เล่นขยับเข้าไปในพื้นที่อันตราย เป็น risk/reward ตัวเดียวในเกมที่ทำให้ "การเดิน" ยังมีความหมาย gem จะรวมเป็นก้อนเดียวเมื่อมีมากเกินไป (ไม่ทำให้เครื่องหน่วง)

## 8. จุดอ่อน / คำวิจารณ์ที่ควรรู้

- ช่วงท้ายจอรกจนมองอะไรไม่เห็น การเล่นกลายเป็น "ดูเฉยๆ"
- Build ที่ดีที่สุดค่อนข้างชัด ผู้เล่นที่รู้แล้วจะเลือกเหมือนกันทุกรอบ ทำให้ความหลากหลายลดลง
- เกมมี "ความลึกลับ" ที่หาเองยาก (อาวุธลับ ด่านลับ) ต้องพึ่ง wiki
- เนื้อหาเยอะจนล้น ไม่มีเรื่องราว ผู้เล่นที่ต้องการเป้าหมายอื่นนอกจากปลดล็อกจะเบื่อ
- ไม่มี co-op ตอนแรก (เพิ่ม local co-op ทีหลังในปี 2023) และไม่มี online co-op

## 9. สิ่งที่ Emberhold นำมาใช้ได้ (และสิ่งที่ไม่ควร)

Emberhold ยืม "เดินอย่างเดียว โจมตีเอง เก็บคริสตัล เลือก perk ตอน level-up" มาจาก VS อยู่แล้ว ส่วนที่ต่างคือ Emberhold มีฐานที่ต้องปกป้อง มี prep phase และเป็น co-op online ดังนั้นสิ่งที่ควรดูคือ **จังหวะและ feedback** ของ VS มากกว่าระบบไอเทม

### ควรนำมาใช้

| แนวคิดจาก VS                               | ปรับใช้กับ Emberhold                                                                                                                       |
| ------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------ |
| Feedback ทุก 10–20 วินาที                  | ตอนนี้ perk มาจาก level-up ควรเช็คว่าความถี่ level-up ในช่วง wave 1–5 ถี่พอหรือไม่ ถ้าห่างเกิน 60 วินาทีจะรู้สึกแห้ง                       |
| Weapon evolution                           | อาวุธของฮีโร่ (ธนู ดาบ คทา) ควรมีขั้นวิวัฒนาการเมื่อเลือก perk สายเดียวกันครบ เช่น ธนู + power 3 ครั้ง → ธนูไฟ ให้ผู้เล่นมีเป้าหมายกลางรอบ |
| Build synergy แบบวิวัฒนาการกับสิ่งก่อสร้าง | Tower ที่อยู่ในรัศมี Shrine → กลายเป็น Blessed Tower เป็น evolution แบบพื้นที่ ต่างจาก VS แต่ให้ความรู้สึกเดียวกัน                         |
| น้ำหนักตัวเลือกตามของที่มี                 | ตอนสุ่ม perk ให้สายที่ผู้เล่นเลือกไปแล้วออกบ่อยขึ้น build จะสม่ำเสมอกว่าสุ่มล้วน                                                           |
| Curse ที่ผู้เล่นเลือกเอง                   | ก่อนเริ่ม run ให้เลือก "คำสาป" เช่น ศัตรูเร็วขึ้น 20% แลก Ember x1.5 เป็นความยากที่ไม่ต้องทำโหมดแยก                                        |
| กล่องสมบัติจาก boss                        | boss wave ทุก 10 wave ดรอปกล่องให้ทีมเลือก perk พิเศษร่วมกัน 1 อย่าง (host เลือก หรือโหวต)                                                 |
| จบรอบไม่รู้สึกแพ้                          | หน้าจอจบเกมควรโชว์ Ember ที่ได้ สถิติ และ "สิ่งที่ปลดล็อกได้ถัดไป" ก่อนปุ่มเล่นใหม่                                                        |
| หน้า Unlocks ที่บอกเงื่อนไข                | ร้านค้าที่มีอยู่แสดงแค่ราคา ควรเพิ่มเงื่อนไข achievement เช่น "ผ่าน wave 10 บนแผนที่หิมะ → ปลดล็อกอาวุธใหม่"                               |
| Gem รวมก้อน                                | คริสตัลที่ตกเยอะควร merge เป็นก้อนใหญ่เมื่อเกิน N ชิ้น ช่วยทั้ง performance และ snapshot size ของ co-op                                    |
| Magnet เป็นสถิติ                           | มีรัศมีดูดคริสตัลเป็น perk สายหนึ่ง ลดความจำเป็นต้องเดินไปเก็บ (แต่อย่าให้ดูดทั้งจอ ไม่งั้นการเดินไร้ความหมาย)                             |

### ไม่ควรนำมาใช้ตรงๆ

- ช่อง 6 อาวุธ + 6 พาสซีฟ: จอแนวตั้งกับมือเดียวไม่มีที่แสดงและผู้เล่นจำไม่ไหว Emberhold ควรมีอาวุธหลัก 1 + perk สาย 3–4 สายพอ
- รอบ 30 นาทีตายตัว: Emberhold เป็น endless + co-op ควรใช้ boss wave เป็นจุดพักแทน และ run เฉลี่ยควรสั้นกว่า (10–20 นาที) เพราะเล่นบนมือถือ
- จอรกช่วงท้าย: co-op 4 คนบนจอเล็ก ถ้าเอฟเฟกต์เต็มจอจะมองฐานไม่เห็น ต้องคุมความหนาแน่นของเอฟเฟกต์ให้ต่ำกว่า VS มาก
- ศัตรูโง่เดินเข้าหาผู้เล่น: ศัตรูของ Emberhold ต้องมีเป้าหมายเป็น keep และสิ่งก่อสร้าง ไม่ใช่ผู้เล่น ไม่งั้น base-defense ไม่มีความหมาย
- ตัวเลขดาเมจเด้งทุกครั้ง: เปลือง draw call บน Three.js และ snapshot ไม่ควรส่ง effect ทุกอัน ทำเฉพาะ crit หรือ kill

### คำถามออกแบบที่ยังเปิดอยู่

1. ความถี่ level-up ปัจจุบัน (XP ต่อ kill กับ threshold) ให้ perk แรกภายในกี่วินาที?
2. ควรมี weapon evolution ต่อฮีโร่หรือไม่ ถ้ามีจะทับกับ perk สาย power/vitality อย่างไร
3. Curse ก่อนเริ่ม run ต้องตกลงร่วมกันใน co-op อย่างไร (host เลือก, โหวต, หรือแยกคนละ curse)
