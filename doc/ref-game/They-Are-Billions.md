# They Are Billions — เอกสารทำความเข้าใจเกมเพื่อใช้อ้างอิง

- ผู้พัฒนา: Numantian Games (สเปน)
- ออก Early Access: ธันวาคม 2017 · เวอร์ชันเต็ม 1.0: มิถุนายน 2019 (เพิ่มโหมด Campaign "The New Empire")
- แพลตฟอร์ม: PC เป็นหลัก ต่อมามี PS4 / Xbox One
- แนวเกม: Real-time strategy + colony builder + survival ธีม steampunk หลังวันสิ้นโลก
- จุดขาย: ซอมบี้บนจอพร้อมกันหลักหมื่นตัว, active pause, permadeath, กลไก "ติดเชื้อลาม"

> จุดประสงค์ของเอกสารนี้คือถอดแก่นของเกมมาเป็นข้อมูลอ้างอิงสำหรับออกแบบ Emberhold ไม่ใช่คู่มือเล่นเกม

---

## 1. Core loop

```
สำรวจ/ขยายฐาน → หาทรัพยากร → สร้างกำแพง/ป้อม/ทหาร → ป้องกัน wave → ซ่อม/ขยายต่อ → wave ใหญ่ขึ้น → ... → Final wave
```

ผู้เล่นเริ่มจาก **Command Center** กลางแผนที่สุ่ม รอบตัวเป็นหมอกและซอมบี้เดินเรื่อยเปื่อย ต้องขยายอาณานิคมออกไปเรื่อยๆ เพื่อเอาทรัพยากรและที่ดิน ในขณะเดียวกันซอมบี้จะโจมตีเป็นระลอก (wave) ที่ใหญ่ขึ้นตามเวลา จบเกมด้วย **Final wave** ขนาดมหึมาที่มาจากทุกทิศ

เกมจบทันทีเมื่อ **Command Center ถูกทำลาย** หรือถูกติดเชื้อ

## 2. โหมดเกม

| โหมด | รายละเอียด |
|---|---|
| Survival | แผนที่สุ่ม เลือกความยาว (เช่น 80 / 100 / 120 / 150 วัน) เลือก % ประชากรซอมบี้ เลือกประเภทแผนที่ ได้คะแนนตามความยาก |
| Campaign (The New Empire) | 48 ภารกิจบนแผนที่โลก มี tech tree ถาวรข้ามภารกิจ มีภารกิจแบบ tactical ที่ควบคุมฮีโร่ตัวเดียว |
| Weekly Challenge | แผนที่เดียวกันทั้งโลก แข่งคะแนน |
| Custom Levels | ผู้เล่นสร้างเอง |

ประเภทแผนที่ใน Survival (แต่ละแบบต่างกันที่ภูมิประเทศ ทรัพยากร และซอมบี้เด่น): Dark Moorland, Frozen Highlands, Desolate Wasteland, Lowlands Peaks, Caustic Lands, Deep Forest, Volcanic Caldera

## 3. ทรัพยากร

| ทรัพยากร | ได้จาก | ใช้ทำอะไร |
|---|---|---|
| Gold | ภาษีจากบ้านพัก, Market, Bank | สร้างทุกอย่าง จ้างทหาร |
| Wood | Sawmill ใกล้ป่า | สิ่งก่อสร้างพื้นฐาน กำแพงไม้ |
| Stone | Quarry ใกล้หิน | กำแพงหิน ป้อมหิน อาคารขั้นสูง |
| Iron | Quarry ใกล้แร่เหล็ก | ทหารขั้นสูง Ballista Executor |
| Oil | Oil Platform บนบ่อน้ำมัน | Lucifer, Thanatos, Titan, Shocking Tower |
| Food | Hunter, Fisherman, Farm | เลี้ยงประชากร บ้านต้องมีอาหารพอ |
| Workers (คนงาน) | บ้านพัก (Tent → Cottage → Stone House) | อาคารทุกหลังต้องใช้คนงาน |
| Energy | Windmill, Power Plant | อาคารส่วนใหญ่ต้องใช้ไฟ |

แก่นคือ **ทุกอย่างพึ่งพากันเป็นลูกโซ่**: ต้องมีบ้านถึงจะมีคนงาน ต้องมีอาหารถึงจะสร้างบ้านได้ ต้องมีไฟถึงจะเปิดโรงงาน การขยายฐานคือการหาที่ดินติดทรัพยากรและปกป้องมัน

## 4. สิ่งก่อสร้าง (คัดมาเฉพาะที่เกี่ยวกับการออกแบบ)

**ที่พัก / เศรษฐกิจ**
- Tent → Cottage → Stone House: ประชากรและภาษีต่อหลังสูงขึ้น ใช้ต้นทุนอัปเกรด "ในที่เดิม" ไม่ต้องรื้อ
- Market / Bank: เพิ่มรายได้ตามจำนวนบ้านในรัศมี (ระบบ radius bonus)
- Warehouse: เพิ่มผลผลิตอาคารเก็บทรัพยากรในรัศมี

**ป้องกัน**
- Wood Wall → Stone Wall, Gate: กั้นทาง ซอมบี้ต้องทุบพัง
- Wood Tower → Stone Tower: ที่ยืนของทหาร ยิงได้ไกลขึ้น
- Ballista: ป้อมยิงกลุ่มระยะไกล ใช้เหล็ก
- Shocking Tower: ฟ้าผ่าโดนหลายตัว ใช้น้ำมัน กินไฟมาก
- Executor: ป้อมขั้นสูงสุด ยิงทะลุแถว
- Wonders (Crystal Palace, Lightning Spire, Silent Beholder, Atlas Transmutator, Victorious): สิ่งก่อสร้างท้ายเกมราคาแพงมาก ให้โบนัสมหาศาลทั้งอาณานิคม

**ทหาร** (ผลิตจาก Soldier Center / Engineering Center)

| หน่วย | บทบาท |
|---|---|
| Ranger | เร็ว เงียบ ราคาถูก ใช้สำรวจและล่อซอมบี้ |
| Soldier | ปืนไรเฟิล เสียงดัง ดึงซอมบี้มา |
| Sniper | ระยะไกล ดาเมจสูง ยิงช้า |
| Lucifer | พ่นไฟ ดาเมจกลุ่มระยะประชิด แต่เผาสิ่งก่อสร้างตัวเองได้ |
| Thanatos | จรวด ดาเมจกลุ่มระยะไกล |
| Titan | หุ่นยักษ์ ท้ายเกม |

ทหารมี **ระดับ Veteran** เมื่อฆ่าได้มาก และมีค่า **เสียง (noise)** แต่ละหน่วยต่างกัน ยิ่งดังยิ่งดึงซอมบี้

## 5. ศัตรู

| ซอมบี้ | ลักษณะ |
|---|---|
| Walker | ช้า เยอะที่สุด |
| Runner | เร็วมาก ทะลุแนวป้องกันบางๆ |
| Harpy | เร็วและปีนกำแพงได้ |
| Chubby | เลือดหนา ตีอาคารแรง |
| Venom | ถ่มพิษระยะไกล ยิงข้ามกำแพงได้ |
| Giant | เลือดเยอะมาก ทุบกำแพงพังในไม่กี่ที |
| Mutant | เร็ว เลือดเยอะ ปรากฏช่วงท้าย |
| Doom Village / Infected Colony | หมู่บ้านซอมบี้บนแผนที่ ต้องบุกเคลียร์ เป็น boss เชิงพื้นที่ |

**Wave** จะประกาศล่วงหน้าพร้อมทิศทางที่มา ผู้เล่นมีเวลาเตรียมตัว ระหว่าง wave ยังมีซอมบี้เดินเรื่อยเปื่อยที่ถูกดึงมาด้วยเสียง

## 6. กลไกที่ทำให้เกมนี้โดดเด่น

### 6.1 การติดเชื้อลาม (Infection cascade)
ซอมบี้ตัวเดียวที่เข้าถึง **บ้านที่มีคน** จะทำให้บ้านหลังนั้นกลายเป็นซอมบี้ทันที และซอมบี้ใหม่ก็ไปติดบ้านข้างๆ ต่อเป็นลูกโซ่ ฐานทั้งฐานอาจล่มได้จากช่องโหว่ช่องเดียว
→ สร้างความตึงเครียดสูงมาก และทำให้ "รูรั่วเล็กๆ" มีความหมาย

### 6.2 Active pause
กดหยุดเวลาได้ตลอด และสั่งสร้าง/สั่งทหารระหว่างหยุดได้ ทำให้เกมที่มีศัตรูหลักหมื่นยังควบคุมได้ด้วยคนเดียว

### 6.3 Permadeath / Ironman
มี save เดียว บันทึกอัตโนมัติ ออกเกมแล้วโหลดใหม่ก็กลับมาตรงเดิม ไม่มี save-scum ทุกการตัดสินใจถาวร

### 6.4 เสียงและการดึงศัตรู
ทุกการกระทำมีเสียง ทหารยิง อาคารทำงาน ซอมบี้ได้ยินแล้วเดินมา ผู้เล่นใช้ Ranger ล่อซอมบี้ทีละกลุ่มออกมาฆ่าได้ (kiting) เป็น skill expression หลักช่วงต้นเกม

### 6.5 ขยายก่อนถูกล้อม
ทรัพยากรบนแผนที่มีจำกัดและอยู่ห่างออกไป ต้องเลือกว่าจะขยายไปทิศไหน ทุกครั้งที่ขยายคือเพิ่มแนวรบที่ต้องป้องกัน

### 6.6 Mayor
ทุกครั้งที่ประชากรถึงเกณฑ์ จะได้เลือก Mayor 1 ใน 2 ที่ให้โบนัสถาวร (เช่น ทหารฟรี ทรัพยากร ส่วนลด) เป็น roguelike-style choice เล็กๆ ระหว่างเกม

### 6.7 การเร่งจังหวะ
Wave แรกๆ เล็กมากจนแทบไม่ต้องกลัว แต่ curve ชันมากช่วงท้าย Final wave คือการทดสอบว่าทุกอย่างที่สร้างมาทั้งเกมพอไหม

## 7. โครงสร้างความยาก
- เลือกจำนวนวันและ % ซอมบี้ → คูณเป็นคะแนน
- แผนที่ยากมีทรัพยากรน้อยและซอมบี้ประเภทอันตรายมากขึ้น
- ความยากมาจาก "การบริหารเวลา" มากกว่า micro ต่อสู้ ถ้าเศรษฐกิจตามไม่ทันจะแพ้ที่ wave ท้าย ไม่ใช่ wave กลาง

## 8. จุดอ่อน / คำวิจารณ์ที่ควรรู้
- ช่วงต้นเกมช้าและซ้ำ (แผนที่สุ่มแต่ opening เหมือนกันทุกครั้ง)
- Permadeath ทำให้เสียเวลา 2–4 ชั่วโมงในครั้งเดียวจากความผิดพลาดเล็กๆ ผู้เล่นบางส่วนหงุดหงิด
- Campaign ถูกวิจารณ์ว่ายาวและมี grind (ภารกิจ tactical ไม่ตรงกับแก่นเกม)
- Pathfinding ทหารและซอมบี้บางครั้งแปลก
- UI เยอะ ต้องเรียนรู้ ไม่เหมาะกับจอเล็ก

## 9. สิ่งที่ Emberhold นำมาใช้ได้ (และสิ่งที่ไม่ควร)

Emberhold เป็นเกมแนวตั้งเล่นมือเดียว ต่อสู้ real-time ควบคุมฮีโร่ตัวเดียว ต่างจาก TAB ที่เป็น RTS จอใหญ่มาก ดังนั้นต้องเลือกเฉพาะ "ความรู้สึก" ไม่ใช่ระบบทั้งก้อน

### ควรนำมาใช้
| แนวคิดจาก TAB | ปรับใช้กับ Emberhold |
|---|---|
| Wave ประกาศล่วงหน้าพร้อมทิศทาง | ตอนนี้ engine มี prep phase อยู่แล้ว เพิ่มลูกศรบอกทิศทาง wave ถัดไปบนขอบจอ ให้ผู้เล่นวางป้อมถูกด้าน |
| ซอมบี้หลากประเภทที่ counter การป้องกันคนละแบบ | Runner ทะลุแนวไปหา keep, Harpy ข้ามกำแพง, Venom ยิงป้อมจากไกล, Giant ทุบกำแพง ทำให้กำแพงอย่างเดียวไม่พอ |
| Infection cascade | ถ้าศัตรูทำลาย Farm/Shrine อาจสปอว์นศัตรูเพิ่ม 1–2 ตัว เพื่อให้การ "ปล่อยให้พัง" มีราคา (ทดลองแบบเบา ไม่ควรลามทั้งฐาน) |
| Radius bonus ของอาคาร | Farm ที่อยู่ติดกันได้โบนัส หรือ Shrine ฮีลป้อมในรัศมี ทำให้การวางตำแหน่งมีความหมาย |
| Mayor choice | มีอยู่แล้วในรูป perk ตอน level-up ขยายเป็น "เลือก 1 ใน 2 ทุก 3 wave" ระดับทีม |
| อัปเกรดในที่เดิม | มีแล้ว (upgrade เมื่ออยู่ใกล้) รักษาไว้ |
| Final wave ที่เป็น climax | endless ไม่มีจบ แต่เพิ่ม "boss wave" ทุก 10 wave ให้มีจุด climax เป็นระยะ |
| Curve ที่ต้นเกมง่าย ท้ายเกมโหด | endless ควรมี curve ชันขึ้นแบบ exponential เบาๆ หลัง wave 10 เพื่อไม่ให้ run ยาวเกินไป |

### ไม่ควรนำมาใช้ตรงๆ
- ทรัพยากร 8 ชนิด: มือถือมือเดียวรับไม่ไหว Emberhold ใช้ gold อย่างเดียวถูกแล้ว อาจเพิ่มได้อีก 1 ชนิดสูงสุด
- Active pause: ขัดกับ co-op real-time ที่ host จำลองอยู่ ไม่ควรมี
- Permadeath ยาว 3 ชั่วโมง: run ของ Emberhold ควรอยู่ที่ 10–20 นาที ความตายต้องเจ็บแต่ไม่เสียเวลา
- ระบบเสียง/noise: ซับซ้อนเกินไปสำหรับจอเล็กและการโจมตีอัตโนมัติ
- การสำรวจแผนที่ใหญ่: แผนที่ Emberhold เล็กและมองเห็นทั้งหมด

### คำถามออกแบบที่ยังเปิดอยู่
1. ควรมี "ทิศทางของ wave" หรือให้ศัตรูมาทุกทิศเสมอ? (ปัจจุบันดูจาก `startWave` ใน engine ว่าสปอว์นอย่างไร)
2. ประเภทศัตรูปัจจุบันมีกี่แบบ พอ counter การป้องกันแต่ละแบบหรือยัง?
3. การเสียสิ่งก่อสร้างตอนนี้ "เจ็บ" พอหรือไม่ เทียบกับ infection cascade ของ TAB
