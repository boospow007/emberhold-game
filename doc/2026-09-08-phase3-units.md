## สิ่งที่เปลี่ยน

### หน่วยทหาร (engine)

1. ชนิดหน่วย 3 แบบใน `UNITS`: ทหารราบ (ประชิด 90 HP), นักธนู (ระยะ 7, 55 HP), อัศวิน (เร็ว 180 HP ใช้คนงาน 2)
2. สิ่งปลูกสร้างกองทัพ 3 ชนิด (แท็บใหม่ "กองทัพ"): ค่ายทหารราบ (ฐาน L1), ค่ายธนู (L2), ค่ายอัศวิน (L3) ผลิตหน่วย **1 นายต่อระดับ** ทันทีที่สร้าง/อัปเกรด และคิดคนงาน `workers × ระดับ` การอัปเกรดค่ายต้องมีคนงานว่าง
3. หน่วยที่ตายจะ **ฟื้นตอนเช้า** (เข้าช่วง prep) ถ้าค่ายยังอยู่ หน่วยทั้งหมดเลือดเต็มตอนเช้า ถ้าค่ายถูกทำลาย หน่วยของค่ายนั้นหายไป
4. AI: โหมด `hold` ยืนประจำจุด สู้ศัตรูที่เข้าใกล้ในรัศมี leash 3.5 แล้วกลับที่; โหมด `follow` เดินตามฮีโร่ในตำแหน่งขบวน ต่อสู้ในรัศมี 4 รอบฮีโร่ ถ้าเจ้าของตายจะเปลี่ยนเป็น hold ตรงนั้น
5. ศัตรูเล็งหน่วยทหารในระยะ 4 เหมือนเล็งผู้เล่น

### ระบบตาม/ปลด และ stack

- คำสั่ง `rally`: หน่วยว่าง (hold) ในรัศมี 9 จากฮีโร่ วิ่งมาตามจนเต็ม stack; `release`: ปลดทุกหน่วยที่ตามให้ยืนอยู่กับที่ ใช้ได้ทั้ง prep และ battle
- `Player.stack = 2 + squad` โดย `squad` เป็นระดับอัปเกรดนอกเกม (0–8) เก็บในคอลัมน์ใหม่ `profiles.squad` (migration 0003) ซื้อในค่ายพักรายการ "ขยายกองกำลัง" ราคา `80 + ระดับ × 60` ตามค่าตั้งต้นใน 02-meta-progression
- ใน co-op แต่ละคนมี stack ของตัวเอง หน่วยที่ปลดแล้วใครก็เรียกได้

### UI

- ปุ่มเดียวมุมล่าง "รวมพล" / "ปลดทหาร" แสดง `ตาม/stack` และจำนวนหน่วยว่างใกล้ตัว พร้อมไอคอนชนิดหน่วยที่ตามอยู่ ปิดเมื่อไม่มีหน่วยว่างและไม่มีหน่วยตาม
- แท็บสร้าง 4 หมวด, จุดหน่วยทหารบน minimap, โมเดลทหาร 3 แบบ (แถบสีบนหลังบอกเจ้าของ) และโมเดลค่าย 3 แบบ
- ค่ายพักเพิ่มรายการ "ขยายกองกำลัง" ระดับ 0–8

### API

- `purchase` รับ `item: 'squad'`, ตัวกรองคำสั่งจาก guest เพิ่ม `rally`/`release`, snapshot ตรวจ `units ≤ 80`

### เทสต์ `tests/units.test.mjs` 6 ข้อ

ผลิตหน่วยและคนงานต่อระดับ, อัปเกรดค่ายต้องมีคนงาน, rally จำกัดตาม stack และรัศมี 9 / release ยืนอยู่กับที่ / หน่วยตามทัน, ใช้ได้ตอน battle, หน่วยสู้และฟื้นตอนเช้า, ค่ายพังแล้วหน่วยหายและศัตรูเล็งหน่วย

## ผลกระทบ / สิ่งที่ต้องทำต่อ

- **ต้อง apply migration 0003** กับ D1 ในเครื่อง (คำสั่งเดียวกับใน CLAUDE.md เปลี่ยนชื่อไฟล์)
- ยังไม่มี: หน่วยเข้าประจำหอคอย, ปลดเฉพาะชนิด (แตะค้าง), โบนัสหน่วยที่ตามฮีโร่, นายทหาร (Captain), หน่วยเครื่องจักร/โรงหล่อ, การสั่งบุกสำหรับ PvP
- ตัวเลขดาเมจ/เลือดของหน่วยยังไม่ได้ปรับสมดุลกับ wave หลังๆ (ศัตรู scale ตาม wave แต่หน่วยไม่ scale) ควรให้หน่วย scale ตามระดับค่ายหรือเทคโนโลยีในเฟสถัดไป
- หน่วยไม่ถูกนับใน `reward()` และไม่มีต้นทุนบำรุง
