## สิ่งที่เปลี่ยน

### เข้าร่วมกลางเกม (late join)

1. `join` รับห้องสถานะ `playing` ด้วย (เดิมเฉพาะ `lobby`) ยังจำกัด 4 คนเท่าเดิม
2. `list` แสดงห้องที่กำลังเล่นพร้อม `status` และ `day` (คอลัมน์ใหม่ `rooms.day` migration 0005 host อัปเดตทุกครั้งที่ส่ง snapshot) UI แสดงป้าย "กำลังเล่น · วันที่ N"
3. ผู้เข้าร่วมใหม่เข้าสู่เกมผ่าน flow เดิม (poll lobby → ได้ snapshot → เข้าเกม) และ **host เป็นคนเพิ่มฮีโร่** ให้ในรอบ sync ถัดไปเมื่อเห็นสมาชิกที่ยังไม่อยู่ใน `world.players`
4. `addPlayer` ให้ผู้เข้าร่วมทีหลัง **ระดับเท่าค่าเฉลี่ยของทีม** และได้จำนวนพร (`picks`) เท่ากับระดับ − 1 เพื่อเลือกเอง ตามข้อเสนอที่ยืนยันใน game-doc ทรัพยากรเป็นกองกลางอยู่แล้ว

### กลับเข้าห้องหลังหลุด (reconnect)

1. `profile` คืน `room` ปัจจุบันถ้าโปรไฟล์นี้ยังเป็นสมาชิกของห้องที่ยังไม่หมดอายุ (code, host, map, seed, days, day, status)
2. หน้าแรกแสดงการ์ด "ห้องของคุณกำลังเล่นอยู่ / คุณยังอยู่ในห้องรอ" พร้อมปุ่มกลับเข้าห้องและออกจากห้อง
3. กลับเข้าห้องแล้ว poll lobby ต่อ: guest ได้ snapshot ล่าสุด; **host ที่หลุดแล้วกลับมาภายใน 45 วินาที** จะรับ snapshot ล่าสุดจากห้องเป็นโลกของตัวเองและจำลองต่อจากจุดนั้น (ไม่ใช่ host migration แต่กู้คืนได้ถ้ากลับมาทัน)
4. `Game` เริ่มตัวนับ `seq` ของคำสั่งจาก `world.acks[ตัวเอง]` เพื่อไม่ให้คำสั่งหลัง reconnect ถูกมองว่าซ้ำและถูกทิ้ง
5. สมาชิกที่หายไปชั่วคราว (< 45 วินาที) ยังอยู่ใน `players` ของ lobby จึงไม่ถูก host ลบออกจากโลก แค่ input ว่างระหว่างนั้น

### เทสต์ co-op

- ข้อเดิม: การ join ห้องที่เริ่มแล้วและเต็ม ได้ 409 (เดิม 404 เพราะห้ามเข้า)
- ข้อใหม่: ห้องที่เล่นอยู่ปรากฏใน list พร้อมวัน, join ได้, lobby คืน snapshot, ผู้มาใหม่ได้ระดับ 5 และ 4 พรตามทีม, `profile` คืนห้องปัจจุบันของทั้ง guest และ host, ออกแล้วเป็น null

## เหตุผล

ข้อกำหนด "Survival co-op join ตามหลังได้" และ README เดิมระบุว่ายังไม่มี reconnect เป็นช่องโหว่ใหญ่ที่สุดของโหมด co-op

## ผลกระทบ / สิ่งที่ต้องทำต่อ

- **ต้อง apply migration 0005** กับ D1 ในเครื่อง
- ยังไม่มี host migration: ถ้า host หายเกิน 45 วินาที ห้องปิด guest ได้ 410 เหมือนเดิม ต้องรอ realtime server (เฟส 6 / PvP)
- ระหว่าง host หาย guest เห็นโลกค้าง (ไม่มีข้อความบอก) ควรเพิ่มข้อความ "รอเจ้าของห้องกลับมา" เมื่อ snapshot ไม่เปลี่ยนเกิน 3 วินาที
- ผู้เข้าร่วมทีหลังเกิดที่ข้างฐานแม่และไม่มีทหาร stack ของตัวเองยังใช้ได้กับหน่วยที่ปลดไว้
