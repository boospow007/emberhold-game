## สิ่งที่เปลี่ยน

### ภูมิประเทศจาก seed (`lib/game/terrain.ts`)

1. แผนที่ขยายจาก 46×46 เป็น **113×113** (`HALF = 56`)
2. **seed** เป็นตัวอักษร 3–8 ตัว (A–Z, 2–9) `randomSeed()`, `normalizeSeed()`, `weeklySeed()` (รูปแบบ `WK2637` จากสัปดาห์ ISO)
3. ความสูงจาก value noise 3 ชั้น ใช้ PRNG แบบ deterministic (mulberry32 + FNV hash) **ไม่ใช้ `Math.random`** เพื่อให้ทุกเครื่องได้แผนที่เดียวกัน
4. ชนิดพื้นที่ตามความสูง: น้ำ (< 0.32), ที่ราบ, เนิน (≥ 0.58), ภูเขา (≥ 0.72 เดินผ่านไม่ได้)
5. **แม่น้ำ** 1 สายพาดจากขอบถึงขอบ มี **จุดข้ามตื้น** 2 จุด, **ทะเลสาบ** 2 แห่ง, ที่ราบรอบฐานรัศมี 8 (แบนสนิท) และ blend ถึงรัศมี 11
6. `carveAccess` ตรวจว่าวงนอกแผนที่เดินถึงฐานได้ ถ้าเปิดน้อยกว่าเกณฑ์จะเจาะทางเดิน 4 ทิศ
7. ต้นไม้/หิน/สายแร่สุ่มจาก seed: ต้นไม้เป็นหย่อมป่า หินและสายแร่อยู่บนเนิน สูงสุด 300 ชิ้น (ทะเลทราย 240)
8. **ความสูงไม่ถูก serialize** ทุกเครื่องสร้างใหม่จาก (seed, map) และ cache ไว้ snapshot ของ co-op จึงมีแค่ `seed` กับ `terrain` (สิ่งกีดขวางที่เปลี่ยนได้)

### Engine

- `newWorld(map, seed?)` ถ้าไม่ส่ง seed จะสุ่ม, `World.seed`
- Pathfinding เป็น flow field ขนาด 113×113 ต่อเป้าหมาย (`fieldFor`) กันน้ำ ภูเขา และสิ่งกีดขวาง; **สะพาน** ทำให้ช่องน้ำนั้นเดินได้ (`passable`)
- `move()` ห้ามเดินลงน้ำ/ขึ้นภูเขา ศัตรูที่เดินขึ้นเนินช้าลง 30%
- ศัตรูสปอว์นบนวง `spawnRadius = min(54, รัศมีฐาน + 16)` และเลือกเฉพาะจุดที่เดินถึงฐานได้ (`reachable`)
- ป้อมบนเนินได้ระยะ +20%
- รัศมีก่อสร้างตามระดับฐานแม่ปรับเป็น 12 / 20 / 30 / 44
- สิ่งก่อสร้างใหม่ 2 ชนิด: **สะพาน** (วางบนน้ำเท่านั้น) และ **กระท่อมชาวประมง** (ต้องมีน้ำในรัศมี 2, +8 อาหาร/ระดับ)
- `waterError` ปฏิเสธการวางบนน้ำ/ภูเขา

### Scene

- พื้นเป็น heightmap mesh พร้อม vertex color ตามชนิดพื้นที่และธีม, ระนาบน้ำโปร่ง, ทุกอย่าง (สิ่งปลูกสร้าง ยูนิต ต้นไม้ คริสตัล เอฟเฟกต์ ghost) วางที่ความสูงจริง
- กล้องตามฮีโร่เต็มที่ (เดิม ×0.75) และตามความสูง, เงาขยับตามกล้อง, fog ไกลขึ้น
- `point()` ยิง ray ซ้ำ 3 รอบเพื่อหาตำแหน่งบนพื้นที่มีความสูง
- `GameScene` รับ `World` แทน `map`

### Seed ใน UI และ API

- หน้าแรก: ช่องกรอก seed + ปุ่มสุ่ม + ปุ่ม "สัปดาห์นี้", รับ `?seed=` จาก URL
- ห้อง co-op เก็บ seed (คอลัมน์ `rooms.seed`) และส่งให้ทุกคนตอน join/lobby
- หน้าจบรอบมีปุ่ม "บันทึก SEED" ค่ายพักแสดงรายการ seed ที่บันทึก (สูงสุด 20) กดเล่นหรือลบได้
- API ใหม่: `seeds`, `seed-save` (idempotent ต่อ seed+map เก็บวันที่ดีที่สุด), `seed-delete`
- ตารางใหม่ `seeds` migration `drizzle/0002_chief_shatterstar.sql`
- snapshot validation เพิ่ม `seed` และ `terrain ≤ 400`
