# ปรับปรุง UI: modal ทรงโค้งมน และ animation ครบทุกส่วน

- วันที่: 2026-09-08
- ผู้แก้ไข: Claude Code
- branch: `feat/ui-polish`
- ไฟล์ที่เกี่ยวข้อง: `app/globals.css` (เพิ่มชั้น "UI polish layer" ท้ายไฟล์ก่อน media query reduced-motion), `app/Game.tsx`
- อ้างอิง: คำขอ "ปรับปรุง ui modal ต่างๆ ให้สวยงามดูไม่เหลี่ยม และมี animation ต่างๆ ครบ"

## สิ่งที่เปลี่ยน

### Modal / Dialog

- พื้นหลังเป็น gradient (`--surface`) ขอบโค้ง 28px (กลางจอ) และ 30px ด้านบน (sheet ล่าง) มี highlight เส้นบน เงาลึก และ handle bar บน sheet
- ฉากหลัง (backdrop) มืดขึ้นและ blur 10px
- **Animation เปิด/ปิดใช้ CSS transition กับ `data-starting-style` / `data-ending-style` ของ base-ui** ซึ่งรอให้ transition จบก่อน unmount: modal กลางจอ scale 0.88→1 พร้อม spring, sheet เลื่อนขึ้นจากล่าง 60px ปิดตัวกลับทาง ปิด animation เดิมของ Tailwind (`animate-in/out`) ด้วย `animation: none`
- หัวข้อ คำอธิบาย และเนื้อหาใน modal ไล่ขึ้น (stagger) ปุ่มปิดเป็นวงกลม หมุน 90° เมื่อ hover

### ปุ่มและการ์ด

- ทุกปุ่มมี transition, กดแล้วย่อ 4%, focus ring สีทอง
- `.primary` เป็น gradient ทอง มีเงาเรือง hover ยกขึ้น 1px และมีแสงวิ่งผ่าน (sheen)
- `.next-wave` เป็น pill พร้อม ring กระเพื่อม, `.perk-button` มี ring กระเพื่อมซ้อนกับ glow เดิม
- การ์ดเลือกอาวุธ/แผนที่/ความยาว, รายการสิ่งก่อสร้าง, พร, ห้อง, สมาชิก, ค่ายพัก: ขอบโค้ง 18–22px, hover ยกขึ้น 2px, เลือกแล้วมี glow ทองและไอคอนเด้ง (bounce)
- รายการใน sheet และ modal ไล่ขึ้นทีละรายการ (nth-child delay)
- แท็บสร้างเป็น pill แท็บที่เลือกเป็นทอง

### HUD ในเกม

- header, ทรัพยากร, เลขวัน, minimap, ปุ่มล่าง ไล่ขึ้นตอนเข้าเกม
- ตัวเลขทรัพยากร **เด้งเมื่อค่าเปลี่ยน** (remount ด้วย `key` ใน Game.tsx) chip คนงานเกินกะพริบ
- toast มี animation เข้า-ค้าง-ออกภายใน 3 วินาที (remount ด้วย `key`), แถบเลือดฐานและ XP เลื่อนนุ่ม, กล่องฟื้นคืนชีพหายใจ, joystick fade-in, แถบวางสิ่งก่อสร้างไล่ขึ้น, แจ้งเตือนเครือข่ายสั่น
- หน้าจบรอบ: ไอคอนเด้งเข้า สถิติ 3 ช่องไล่ขึ้นทีละช่อง แต้มที่ได้เด้ง ปุ่มตามมา

### หน้าแรก

- หัวเรื่อง คำอธิบาย และแผงตั้งค่าไล่ขึ้นตอนโหลด

### เข้าถึงได้

- `prefers-reduced-motion: reduce` ปิดทุก animation/transition (กฎเดิม) base-ui จะ unmount ทันทีเมื่อไม่มี transition

## แก้ไขเพิ่มเติม (รอบสอง วันเดียวกัน)

- **บั๊กจากรอบแรก**: keyframe `ui-rise` จบด้วย `transform: translateY(0)` ทับ `translateX(-50%)` ที่ใช้จัดกลาง ทำให้แถบยืนยันการวางสิ่งก่อสร้าง (`.placement-bar`) และแถบเลือดฐาน (`.keep-health`) เลื่อนไปทางขวาจนล้นจอบนมือถือ แก้ด้วย keyframe `ui-rise-centered` ที่รักษา translateX(-50%) และ `ui-breathe-x` สำหรับกล่องฟื้นคืนชีพ
- แถบยืนยันการวางให้ปุ่มขึ้นบรรทัดใหม่ได้เมื่อจอแคบ
- modal บนจอกว้าง ≤ 700px ลด padding เป็น 22px และจำกัด `max-height` ให้อยู่ในจอเสมอพร้อม scroll ภายใน จอเตี้ย ≤ 700px ซ่อนคำอธิบายในหน้าจบรอบและลดช่องว่าง

## เหตุผล

UI เดิมเป็นกล่องเหลี่ยม ไม่มี feedback ตอนกด และ modal โผล่ทันที ผู้ใช้ต้องการความสวยงามและ animation ครบ

## ผลกระทบ / สิ่งที่ต้องทำต่อ

- ไม่มีการเปลี่ยน logic เกม/API
- ค่าสีและระยะยังคงชุดเดิม (ทอง #f2c36d บนเขียวเข้ม) แค่เพิ่ม gradient และเงา
- ข้อสังเกตตอนทดสอบ: เมื่อแท็บเบราว์เซอร์ถูกซ่อน (document.hidden) transition/animation จะหยุด ทำให้ screenshot กลางทางดูโปร่ง ในการใช้งานจริงไม่มีผล
- ยังไม่ได้ทำ: animation ของโมเดล 3D (เช่น ฮีโร่โยกตอนเดิน) และ transition ระหว่างหน้าแรก↔เกม
