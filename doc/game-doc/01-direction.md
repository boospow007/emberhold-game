- วันที่: 2026-09-08
- ที่มา: สรุปจากเจ้าของโปรเจกต์ + เอกสารอ้างอิงใน `doc/ref-game/`
- สถานะ: v0.3 — คำถามหลัก 6 ข้อและคำถามรอบสองได้รับคำตอบแล้ว (2026-09-08) นิยาม 1 วัน = 1 wave ที่ผู้เล่นกดเริ่มเอง

## 1. ภาพรวม

Emberhold คือเกมสร้างฐานและป้องกัน wave แบบ real-time บนแผนที่ขนาดใหญ่ ผู้เล่นควบคุมฮีโร่ตัวเดียวในสนาม เก็บทรัพยากร สร้างเมือง ผลิตทหาร และป้องกันฐานแม่จนครบจำนวนวันที่เลือก หรืออยู่ให้นานที่สุดในโหมดไม่จำกัด เล่นได้คนเดียว ร่วมกับเพื่อน หรือแข่งกันเอง

แก่นที่ต้องรักษาไว้จาก prototype ปัจจุบัน

- ฮีโร่ตัวเดียวในสนามที่เดินเองและโจมตีอัตโนมัติ (จาก Vampire Survivors / Thronefall)
- ช่วงเตรียมตัวสลับกับช่วงต่อสู้ และ preview ของ wave ถัดไป (จาก Thronefall)
- วางสิ่งปลูกสร้างได้อิสระ ไม่ใช่จุดตายตัว
- ความก้าวหน้าถาวรข้าม run ผ่านแต้ม Ember

แก่นที่เพิ่มเข้ามาในทิศทางใหม่ (จาก They Are Billions)

- แผนที่ใหญ่ที่ต้องขยายออกไปหาทรัพยากร
- ทรัพยากรหลายชนิดและห่วงโซ่การผลิต
- ประชากรเป็นตัวจำกัดการเติบโต
- ฐานแม่เป็นตัวปลดล็อกระดับสิ่งปลูกสร้าง

**[กำหนด]** แพลตฟอร์มคือ **แนวตั้ง เล่นมือเดียว** (ยืนยัน 2026-09-08) ทุกระบบที่เพิ่มเข้ามาต้องออกแบบ UI ให้อยู่ในข้อจำกัดนี้

> **ผลของข้อกำหนดนี้** ทรัพยากรหลายชนิดและสิ่งปลูกสร้าง 25+ ชนิดต้องถูกย่อยให้ใช้งานด้วยนิ้วเดียวได้ แนวทางที่เสนอ: แถบทรัพยากรบรรทัดเดียวด้านบน, เมนูสร้างเป็น drawer เลื่อนจากล่างแบ่งตามหมวด 5 หมวด, ทุกการสั่งใช้ "แตะครั้งเดียว" หรือ "ลากแล้วปล่อย" ไม่มีการกดค้างซ้อน ต้องมีเอกสาร UI แยก (`06-ui-portrait.md`) ก่อนเริ่มทำระบบทรัพยากร

## 2. แผนที่

**[กำหนด]**

- แผนที่ขนาดใหญ่ ใหญ่กว่า prototype ปัจจุบันหลายเท่า
- มีระดับความสูง เนินเขาและภูเขา
- มีแหล่งน้ำ ธารน้ำหรือบ่อน้ำ

**[เสนอ]** ผลของภูมิประเทศต่อ gameplay เพื่อให้ความสูงและน้ำมีความหมาย ไม่ใช่แค่ฉาก

| ภูมิประเทศ     | ผลที่เสนอ                                                                       |
| -------------- | ------------------------------------------------------------------------------- |
| ที่สูง         | หน่วยยิงระยะไกลและหอคอยบนที่สูงได้ระยะ +20% และมองเห็นไกลขึ้น ศัตรูปีนขึ้นช้าลง |
| ภูเขา          | ผ่านไม่ได้ ใช้เป็นกำแพงธรรมชาติ แร่หินและเหล็กอยู่ตีนเขา                        |
| ธารน้ำ         | ผ่านไม่ได้ยกเว้นจุดข้ามหรือสะพานที่สร้างเอง บีบเส้นทางศัตรูให้เป็นคอขวด         |
| บ่อน้ำ/ทะเลสาบ | สร้างกระท่อมชาวประมงริมฝั่งเพื่อเอาอาหาร                                        |
| ป่า            | แหล่งไม้ ตัดแล้วพื้นที่ว่างสร้างได้                                             |
| ที่ราบ         | ฟาร์มให้ผลผลิตดีที่สุด                                                          |

**[เสนอ]** แผนที่สุ่มจากชุดกฎ (procedural) โดยมี "ธีม" 3 แบบตาม prototype เดิม คือป่า ทะเลทราย หิมะ แต่ละธีมมีสัดส่วนทรัพยากรและศัตรูเด่นต่างกัน ฐานแม่เริ่มกลางแผนที่เสมอ ศัตรูสปอว์นจากขอบ

**[กำหนด]** แผนที่ **สุ่มจาก seed** ทุกครั้ง ผู้เล่นเห็น seed ก่อนเริ่ม และ **กด save seed** เก็บไว้เล่นซ้ำได้ถ้าชอบ (ยืนยัน 2026-09-08)

**[เสนอ]** รายละเอียด seed

- seed เป็นตัวอักษร 8 ตัว พิมพ์หรือวางแทนได้ เพื่อแชร์ให้เพื่อน
- seed เดียวกัน + ธีมเดียวกัน + ความยาวเดียวกัน ต้องได้แผนที่และลำดับ wave เหมือนกันทุกเครื่อง (ต้องใช้ PRNG แบบ deterministic ใน engine ห้ามใช้ `Math.random`)
- เก็บ seed ที่ save ไว้ในโปรไฟล์ (ตาราง D1 ใหม่) พร้อมชื่อ สถิติที่ดีที่สุดบน seed นั้น
- โหมด co-op ใช้ seed ของ host และส่งให้ guest ตอน join
- **[เสนอ]** "Seed ประจำสัปดาห์" ให้ทุกคนเล่นแผนที่เดียวกันแข่งคะแนน (จาก They Are Billions Weekly Challenge)

## 3. ประชากรและบ้าน

**[กำหนด]**

- สิ่งปลูกสร้างป้องกันและทหาร ถูกจำกัดด้วยจำนวน worker
- worker มาจากบ้าน บ้านแต่ละระดับให้ worker ต่างกัน เช่น ระดับ 1 = 2 คน, ระดับ 2 = 5 คน, ระดับ 3 = 10 คน
- อัปเกรดบ้านเพื่อเพิ่ม worker

**[เสนอ]** รายละเอียดระบบ

- แสดง `worker ที่ใช้ / worker ทั้งหมด` ตลอดเวลาบน HUD เหมือน supply ใน RTS
- แต่ละสิ่งปลูกสร้างและทหารมี "ต้นทุน worker" ที่ต่างกัน เช่น หอธนู 1, บัลลิสตา 2, ทหารราบ 1, อัศวิน 2
- บ้านต้องมี **อาหาร** พอถึงจะอัปเกรดได้ (เชื่อมกับระบบทรัพยากร) เพื่อไม่ให้สแปมบ้านอย่างเดียว
- บ้านที่ถูกทำลายทำให้ worker หาย สิ่งปลูกสร้างที่ขาด worker ทำงานช้าลงหรือหยุด ไม่ถึงกับพัง
- **[เสนอ]** นำ infection แบบเบาจาก They Are Billions มาใช้: ศัตรูบางชนิดที่ทำลายบ้านจะสปอว์นศัตรูเพิ่ม 1–2 ตัว ทำให้บ้านต้องอยู่หลังแนวป้องกัน

## 4. ฐานแม่และระดับสิ่งปลูกสร้าง

**[กำหนด]**

- สิ่งปลูกสร้างแต่ละระดับ (level) ถูกจำกัดด้วยระดับของฐานแม่
- ต้องอัปเกรดฐานแม่ก่อนถึงจะอัปเกรดสิ่งปลูกสร้างอื่นไปถึงระดับนั้นได้

**[เสนอ]** โครงสร้าง 4 ระดับ

| ระดับฐานแม่  | ปลดล็อก                                                       | ต้นทุนโดยประมาณ                           |
| ------------ | ------------------------------------------------------------- | ----------------------------------------- |
| 1 (เริ่มต้น) | บ้าน L1, ฟาร์ม, โรงเลื่อย, หอไม้, กำแพงไม้, ค่ายทหารราบ       | —                                         |
| 2            | บ้าน L2, เหมืองหิน, หอหิน, กำแพงหิน, ค่ายธนู, บ้านวิจัย, ตลาด | ไม้ + หิน                                 |
| 3            | บ้าน L3, เหมืองเหล็ก, บัลลิสตา, ค่ายอัศวิน, โรงหล่อ, โกดัง    | หิน + เหล็ก                               |
| 4            | สิ่งปลูกสร้างพิเศษ (Wonder), หน่วยพิเศษ, หอสายฟ้า             | เหล็ก + ทองมาก (ไม่มีน้ำมันในเวอร์ชันแรก) |

- อัปเกรดฐานแม่ใช้เวลานาน และระหว่างอัปเกรดฐานแม่ **เปราะบาง** (เลือดลดชั่วคราวหรือหยุดยิง) เพื่อให้จังหวะอัปเกรดเป็นการตัดสินใจ
- **[กำหนด]** (2026-09-08) ระยะวางสิ่งก่อสร้าง **นับจากสิ่งก่อสร้างชิ้นที่ใกล้ที่สุด** ไม่ใช่จากฐานแม่ (ระยะเชื่อม 8/10/12/14 ตามระดับฐานแม่) ฐานจึงโตเป็นสายไปทางทรัพยากรได้ อัปเกรดฐานแม่ทำให้ระยะเชื่อมยาวขึ้น
- **[กำหนด]** โรงเลื่อยผลิตต่อเนื่อง (+5 ไม้ทุก 5 วินาที ต่อระดับ) จนต้นไม้ในรัศมีหมด ไม่ใช่จ่ายตอนจบวัน
- **[กำหนด]** ห่วงโซ่ทรัพยากรต้องไม่ตัน: สิ่งที่ใช้อัปฐานเป็นระดับถัดไปต้องหาได้จากระดับปัจจุบัน

## 5. ทรัพยากร

**[กำหนด]**

- ทรัพยากรหลากหลาย อ้างอิงชุดจาก They Are Billions
- ทอง: ได้จากเหมือง และจากการชนะ wave
- ไม้: ผู้เล่นต้อง **ตัดไม้ด้วยตัวเอง** (ฮีโร่เดินไปตัด)

**[เสนอ]** ชุดทรัพยากรและแหล่งที่มา ปรับจาก They Are Billions ให้เข้ากับการมีฮีโร่ในสนาม

| ทรัพยากร | แหล่ง                                                  | ใช้กับ                             | หมายเหตุ                                                                           |
| -------- | ------------------------------------------------------ | ---------------------------------- | ---------------------------------------------------------------------------------- |
| ทอง      | เหมืองทอง, รางวัล wave, ศัตรูตก                        | ทุกอย่าง, จ้างทหาร                 | ทรัพยากรกลาง                                                                       |
| ไม้      | ฮีโร่ตัดต้นไม้เอง; ภายหลังโรงเลื่อยตัดอัตโนมัติในรัศมี | สิ่งปลูกสร้างพื้นฐาน กำแพงไม้      | การตัดเองคือกิจกรรมช่วงต้นเกม โรงเลื่อยคือการ "ปลดปล่อย" ฮีโร่ในช่วงกลางเกม        |
| หิน      | เหมืองหินใกล้ภูเขา                                     | กำแพงหิน หอหิน ฐานแม่ L2           |                                                                                    |
| เหล็ก    | เหมืองเหล็กใกล้ภูเขา (หายากกว่าหิน)                    | บัลลิสตา อัศวิน ฐานแม่ L3          |                                                                                    |
| อาหาร    | ฟาร์มบนที่ราบ, นายพรานใกล้ป่า, ชาวประมงริมน้ำ          | เลี้ยงบ้าน จำเป็นต่อการอัปเกรดบ้าน |                                                                                    |
| น้ำมัน   | —                                                      | —                                  | **[กำหนด]** ตัดออกจากเวอร์ชันแรก (2026-09-08) อาจกลับมาเป็นทรัพยากรระดับ 4 ภายหลัง |
| worker   | บ้าน                                                   | ทุกสิ่งปลูกสร้างและทหาร            | ดูข้อ 3                                                                            |
| พลังงาน  | —                                                      | —                                  | **[กำหนด]** ตัดออกจากเวอร์ชันแรก (2026-09-08)                                      |

**[เสนอ]** เหมืองทุกชนิดต้องสร้าง **บนแหล่งแร่** ที่มีจำกัดบนแผนที่ ทำให้การขยายออกไปหาแร่เป็นเหตุผลหลักในการออกจากฐาน

**[เสนอ]** ในโหมด co-op ทรัพยากรเป็น **กองกลางของทีม** (prototype ปัจจุบันก็ใช้ทองรวม) ยกเว้น XP และ perk ที่เป็นของแต่ละคน

## 6. สิ่งปลูกสร้าง

**[กำหนด]**

- มีสิ่งปลูกสร้างหลากหลาย จำนวนเยอะ
- ต้องวางแผนให้สมดุลและสนุก
- ตัวอย่างที่ต้องมี: บ้านผลิตทหาร, บ้านวิจัย

**[เสนอ]** แคตตาล็อกร่างแรก แบ่ง 5 หมวด (ตัวเลขทั้งหมดเป็นค่าตั้งต้นสำหรับปรับสมดุล)

### 6.1 ที่พักและเศรษฐกิจ

| ชื่อ                    | ระดับฐานแม่ | หน้าที่                                |
| ----------------------- | ----------- | -------------------------------------- |
| บ้าน (L1/L2/L3)         | 1/2/3       | worker 2/5/10 ต้องการอาหาร             |
| ฟาร์ม                   | 1           | อาหาร โบนัสบนที่ราบ                    |
| กระท่อมนายพราน          | 1           | อาหาร ต้องใกล้ป่า                      |
| กระท่อมชาวประมง         | 1           | อาหาร ต้องริมน้ำ                       |
| โรงเลื่อย               | 1           | ตัดไม้อัตโนมัติในรัศมี                 |
| เหมืองทอง / หิน / เหล็ก | 1/2/3       | ต้องสร้างบนแหล่งแร่                    |
| ตลาด                    | 2           | เพิ่มทองจากบ้านในรัศมี หรือแลกทรัพยากร |
| โกดัง                   | 3           | เพิ่มผลผลิตอาคารเก็บทรัพยากรในรัศมี    |

### 6.2 ทหาร

| ชื่อ        | ระดับฐานแม่ | ผลิต                                                        |
| ----------- | ----------- | ----------------------------------------------------------- |
| ค่ายทหารราบ | 1           | ทหารราบ (ถูก ประชิด)                                        |
| ค่ายธนู     | 2           | นักธนู (ระยะไกล เลือดน้อย)                                  |
| ค่ายอัศวิน  | 3           | อัศวิน (เร็ว เลือดหนา ใช้เหล็ก)                             |
| โรงหล่อ     | 3           | หน่วยเครื่องจักร (บัลลิสตาเคลื่อนที่, ต่อไปคือหน่วยระดับ 4) |

ทหารประจำที่หอคอยหรือกำแพงได้ และตามฮีโร่ได้ด้วยปุ่มเดียว "ตามฉัน / กลับที่" (จาก Thronefall)

### 6.3 ป้องกัน

| ชื่อ                | ระดับฐานแม่ | ลักษณะ                             |
| ------------------- | ----------- | ---------------------------------- |
| กำแพงไม้ → กำแพงหิน | 1 → 2       | กั้นทาง อัปเกรดในที่เดิม           |
| ประตู               | 1           | ทหารตัวเองผ่านได้ ศัตรูต้องทุบ     |
| หอไม้ → หอหิน       | 1 → 2       | ที่ยืนของทหาร ยิงไกลขึ้น           |
| หอธนูอัตโนมัติ      | 2           | ยิงเองไม่ต้องใช้ทหาร แต่ใช้ worker |
| หอน้ำแข็ง (Frost)   | 2           | ชะลอ (มีใน prototype แล้ว)         |
| บัลลิสตา            | 3           | ดาเมจกลุ่มระยะไกล                  |
| หอสายฟ้า            | 4           | โดนหลายตัว ใช้เหล็กมาก             |
| กับดัก              | 2           | ราคาถูก ใช้ครั้งเดียว วางบนเส้นทาง |

| สะพาน            | 1           | ข้ามธารน้ำ สร้างได้เฉพาะจุดแคบ                |

### 6.5 พิเศษ (ระดับ 4)

สิ่งปลูกสร้างท้ายเกมราคาแพงมาก ให้โบนัสทั้งฐาน 1 อย่าง เช่น ทหารทั้งหมดดาเมจ +25%, กำแพงซ่อมตัวเอง, ทองเพิ่ม 2 เท่า สร้างได้ 1 หลังต่อ run เป็นเป้าหมายระยะยาวในโหมด 120–150 วัน

### 6.6 บ้านวิจัย

**[เสนอ]** เทคโนโลยีใน run ที่ซื้อด้วยทรัพยากรและใช้เวลาวิจัย แยกจาก perk ของฮีโร่ เช่น

- ธนูไฟ: หอธนูและนักธนูติดไฟ
- กำแพงหนาม: ศัตรูที่ตีกำแพงโดนดาเมจ
- เกษตรกรรม: ฟาร์ม +50%
- โลหะวิทยา: ลดต้นทุนเหล็ก
- ให้ทุก run มีเส้นทางวิจัยไม่เกิน 8–12 อย่าง เลือกได้ราว 4–6 อย่างต่อ run เพื่อให้แต่ละ run ต่างกัน

**[เสนอ]** หลักการสมดุล

- ทุกสิ่งปลูกสร้างป้องกันต้องมีศัตรูอย่างน้อย 1 ชนิดที่ counter มัน (บินข้ามกำแพง, ยิงไกลกว่าหอ, ทุบกำแพงเร็ว)
- ไม่มีสิ่งปลูกสร้างที่ "ดีกว่าทุกด้าน" ทุกการอัปเกรดมีทางแยก 2 ทาง
- ต้นทุน worker ทำให้ผู้เล่นเลือกระหว่างหอคอยจำนวนมากกับทหารจำนวนมากไม่ได้พร้อมกัน

## 7. ความยาวของเกม

**[กำหนด]**

- เลือกความยาวก่อนเริ่ม: 80 / 100 / 120 / 150 วัน
- หรือ **ไม่จำกัด** เล่นจนแพ้

**[กำหนด]** (2026-09-08)

- **1 วัน = 1 wave**
- ช่วง prep **ไม่มีตัวจับเวลา** ผู้เล่น **กดเริ่ม wave เอง** เมื่อพร้อม (prototype ปัจจุบันก็ทำแบบนี้อยู่แล้วผ่าน `startWave`)

**[เสนอ]** ผลที่ตามมา

- ความยาว 80 วัน = 80 wave ระยะเวลาจริงขึ้นกับผู้เล่น (ประมาณ 1.5–3 ชั่วโมง) จึงยังต้องมี **save กลาง run** สำหรับโหมดเดี่ยว โดย save อัตโนมัติทุกครั้งที่จบ wave (ตอนเข้า prep) เพราะเป็นจุดที่ state นิ่งที่สุด
- ใน co-op host เป็นคนกดเริ่ม wave และทุกคนเห็นปุ่ม "พร้อม" เพื่อบอก host (ไม่บังคับ)
- เพื่อไม่ให้ผู้เล่นตุนทรัพยากรใน prep นานเกินไปจนเกมไร้ความกดดัน เสนอให้ **รายได้จากฟาร์ม/เหมืองจ่ายตอนจบ wave** เท่านั้น (เหมือน Thronefall) ไม่ใช่ตามเวลาจริง ส่วนการตัดไม้ด้วยตัวเองใน prep ยังได้ไม้ตามปกติ เพราะเป็นกิจกรรมที่ตั้งใจให้ทำช่วงนั้น
- วันในเกมแสดงเป็นตัวเลข "วันที่ 12 / 80" บน HUD ทั้ง prep และ battle
- โหมดจำกัดวัน: มี **Final wave** วันสุดท้ายเป็น climax ชนะแล้วได้ Ember ก้อนใหญ่ตามความยาว
- โหมดไม่จำกัด: ไม่มีชนะ มี **boss wave ทุก 10 วัน** เป็นจุดหมายย่อย และ curve ความยากชันขึ้นหลังวัน 100
- **[เสนอ]** เพิ่มตัวเลือกความยาวสั้น 30 วัน สำหรับผู้เล่นใหม่และการทดสอบ
- ตัวคูณคะแนน/Ember ตามความยาวและ mutator ที่เปิด (จาก They Are Billions และ Thronefall)
- **[กำหนด]** Ember และร้านค้าถาวรใช้เฉพาะโหมด Survival (เดี่ยวและ co-op) ไม่มีใน PvP (2026-09-08)

## 8. โหมดเกม

**[กำหนด]** 3 โหมด

### 8.1 Survival (เดี่ยว)

เล่นคนเดียว เลือกความยาว แผนที่ ฮีโร่

### 8.2 Survival Co-op

- เล่นร่วมกันสูงสุด 4 คน (ตาม prototype)
- **เข้าร่วมกลางเกมได้** (late join / drop-in)
- **[เสนอ]** ผู้เล่นที่เข้าทีหลังได้ฮีโร่ระดับตามค่าเฉลี่ยของทีมและทรัพยากรกองกลาง ไม่ต้องเริ่มจากศูนย์
- **[เสนอ]** ทุกคนสร้างได้ทุกที่ แต่มี "เจ้าของ" ต่อสิ่งปลูกสร้างเพื่อแสดงผลงานตอนจบเกม

### 8.3 PvP

**[กำหนด]** (2026-09-08)

- **ทำทีหลัง** หลังจาก Survival และ Co-op เสร็จ
- ต้องสร้างห้อง รอผู้เล่นครบและกดพร้อมทุกคนแล้วค่อยเริ่ม
- **ไม่มีศัตรู wave จาก NPC** ผู้เล่นตีกันเองเท่านั้น สไตล์ RTS อย่าง Command & Conquer: Yuri's Revenge
- **ทุกคนเท่าเทียมกัน** อัปเกรดนอกเกม (Ember) ไม่มีผลใน PvP ทุกคนเริ่มด้วยฮีโร่ ทหาร และเทคโนโลยีชุดเดียวกัน ยกเว้นของตกแต่ง

**[เสนอ]**

- รูปแบบ 1v1 และ 2v2 บนแผนที่สมมาตรจาก seed เดียวกัน ฐานอยู่คนละมุม ทรัพยากรวางแบบกระจก
- ชนะเมื่อฐานแม่ฝ่ายตรงข้ามพัง
- ทหารสั่งบุกไปยังจุดที่เลือกได้ นอกเหนือจากตามฮีโร่ (ดูข้อ 8.4)
- เพราะไม่มี wave บังคับจังหวะ ต้องมีกลไกกัน "ตั้งรับอย่างเดียวจนเสมอ" เช่น แหล่งแร่กลางแผนที่ที่ต้องออกไปยึด หรือรายได้จากเหมืองในฐานลดลงตามเวลา
- **[คำถาม]** PvP ใช้กฎทรัพยากรและสิ่งปลูกสร้างเต็มชุด หรือชุดย่อเพื่อให้แมตช์จบใน 20–30 นาที (ยังไม่ต้องตอบตอนนี้ เพราะ PvP ทำทีหลัง)

### 8.4 การควบคุมหน่วยทหาร (ทุกโหมด)

**[กำหนด]** (2026-09-08)

- ผู้เล่นสั่งให้ **unit เดินตามฮีโร่** ได้
- **ปลด** unit ออกได้ unit ที่ถูกปลดจะ **ยืนอยู่กับที่** ตรงนั้น
- จำนวน unit ที่พาไปพร้อมกันได้ (**stack**) จำกัด และเพิ่มได้จาก **อัปเกรดนอกเกม**

**[เสนอ]** รายละเอียดสำหรับมือเดียวแนวตั้ง

- ปุ่มเดียวมุมล่าง "รวมพล / ปลด" แตะครั้งแรก: unit ว่างในรัศมีวิ่งมาตามจนเต็ม stack แตะอีกครั้ง: ปลดทั้งหมด ณ ตำแหน่งปัจจุบัน
- แตะค้างที่ปุ่ม: เปิดแผงเล็กเลือกปลดเฉพาะชนิด (เช่น ปลดเฉพาะธนู) เป็นตัวเลือกขั้นสูง ไม่บังคับใช้
- unit ที่ตามอยู่แสดงเป็นไอคอนเรียงเหนือปุ่ม เช่น ⚔️×3 🏹×2 พร้อมตัวเลข `5/6`
- unit ที่ถูกปลดจะเข้าประจำหอคอยหรือกำแพงอัตโนมัติถ้าปลดใกล้ๆ และป้องกันจุดนั้นจนถูกเรียกใหม่
- unit ที่ตามฮีโร่ได้โบนัสเล็กน้อย (เช่น ฟื้นเลือดช้าๆ) เพื่อให้การ "พาไป" มีความหมาย ไม่ใช่แค่การเคลื่อนย้าย
- stack เริ่มต้น 2 ตัว อัปเกรดนอกเกมได้สูงสุด 8–10 ตัว (ดูรายละเอียดใน `02-meta-progression.md`)
- ใน co-op แต่ละคนมี stack ของตัวเอง unit ที่ถูกปลดเป็นของทีม ใครก็เรียกได้
- ใน PvP stack เท่ากันทุกคน (ค่ากลางที่กำหนดในกฎ PvP) ไม่ใช้ค่าจากอัปเกรด
