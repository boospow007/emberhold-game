# 02 — อัปเกรดนอกเกมและวงจรเล่นซ้ำ (v0.2)

- วันที่: 2026-09-08
- ที่มา: ข้อกำหนดจากเจ้าของโปรเจกต์ + Vampire Survivors (ร้านค้าถาวร, ปลดล็อกผ่าน achievement) + They Are Billions (Weekly Challenge) + Thronefall (mutator)
- สถานะ: v0.2 — ตัวเลขทั้งหมดได้รับการยืนยันเป็น **ค่าตั้งต้นสำหรับทดลองเล่น** (2026-09-08) ปรับได้หลัง playtest; ภารกิจรายวันเลื่อนออกจากเวอร์ชันแรก

---

## 1. เป้าหมายของระบบ

**[กำหนด]**
- ต้องวางแผนอัปเกรดนอกเกมให้ดี เพื่อให้ผู้เล่น **กลับมาเล่นซ้ำบ่อยๆ** เก็บแต้มไปอัปเกรดต่อ นอกเหนือจากความก้าวหน้าในเกม
- จำนวน unit ที่พาไปได้ (stack) เป็นหนึ่งในอัปเกรดนอกเกม
- ใช้เฉพาะ Survival ไม่มีผลใน PvP

**[เสนอ]** หลักการ 4 ข้อที่ทุกอัปเกรดต้องผ่าน
1. **เห็นเป้าถัดไปเสมอ** ผู้เล่นต้องรู้ว่า "อีก X Ember จะได้อะไร" ทุกครั้งที่จบ run (จาก Vampire Survivors)
2. **เปลี่ยนวิธีเล่น ไม่ใช่แค่ตัวเลข** อัปเกรดที่ดีที่สุดคืออันที่เปิดตัวเลือกใหม่ (unit ชนิดใหม่, สิ่งปลูกสร้างใหม่) อัปเกรดตัวเลข (+5% ดาเมจ) มีได้แต่ต้องไม่ใช่ตัวหลัก
3. **ไม่ทำให้เกมง่ายจนเสียความท้าทาย** ผู้เล่นที่อัปเกรดเต็มควรอยู่รอด 150 วันได้ด้วยฝีมือ ไม่ใช่ด้วยตัวเลข ใช้เพดานและ mutator เป็นตัวถ่วง
4. **run สั้นก็ได้ของ** ทุก run ให้ Ember แม้ตายวันที่ 5 เพื่อให้ "ลองอีกรอบ" ไม่รู้สึกเสียเปล่า

## 2. สกุลเงินและแหล่งที่มา

### 2.1 Ember (สกุลเงินหลัก)
ได้จาก run ใน Survival ทุกโหมด (เดี่ยวและ co-op) จำนวนที่ได้คำนวณตอนจบ run

| แหล่ง | สูตรที่เสนอ | หมายเหตุ |
|---|---|---|
| วันที่รอด (= wave ที่ผ่าน) | 3 Ember ต่อวัน | ตัวหลัก ทำให้ "อยู่นานขึ้นอีกวัน" มีค่าเสมอ; 1 วัน = 1 wave ตาม `01-direction.md` ข้อ 7 |
| ชนะ wave | 5 + wave × 0.5 | wave หลังๆ มีค่ามากขึ้น (นับแยกจากวันที่รอด เพราะวันที่รอดนับแม้ตายกลาง wave นั้น) |
| ฆ่าศัตรู | 1 ต่อ 20 ตัว, boss 15 ตัวละ | |
| จบครบตามความยาวที่เลือก | โบนัส 80 / 120 / 180 / 250 ตาม 80/100/120/150 วัน | climax reward |
| ตัวคูณความยาก | ×1.0 พื้นฐาน, mutator แต่ละตัว +0.15 ถึง +0.5 | ดูข้อ 5 |
| ตัวคูณ co-op | ×1.1 เมื่อเล่น 2 คนขึ้นไป | จูงใจให้ชวนเพื่อน ไม่มากจนเดี่ยวไร้ค่า |
| Seed ประจำสัปดาห์ | โบนัสครั้งแรกของสัปดาห์ 100 | ดูข้อ 6 |

เป้าหมายตัวเลข: run ปกติ 20–30 นาที (ตายราววันที่ 20–30) ได้ประมาณ 100–150 Ember อัปเกรดชิ้นแรกๆ ราคา 50–150 เพื่อให้ **ทุก 1–2 run ซื้ออะไรได้ 1 อย่าง** ในช่วง 10 ชั่วโมงแรก

**[กำหนด]** ตัวเลขทั้งหมดในเอกสารนี้เป็น **ค่าตั้งต้น** ใช้ไปก่อนแล้วปรับจากการทดลองเล่น (2026-09-08) สิ่งที่ต้องวัดตอน playtest
- Ember เฉลี่ยต่อ run และต่อชั่วโมง
- จำนวน run ก่อนซื้ออัปเกรดชิ้นแรก ชิ้นที่ 5 และชิ้นที่ 10
- อัปเกรดไหนไม่มีใครซื้อ (สัญญาณว่าแพงไปหรือไม่น่าสนใจ)

### 2.2 Achievement / Milestone (ปลดล็อกโดยตรง ไม่ผ่าน Ember)
ของบางอย่างซื้อไม่ได้ ต้องทำเงื่อนไข เพื่อให้มีเป้าหมายที่ไม่ใช่การเก็บแต้ม (จาก Vampire Survivors) ตัวอย่าง
- รอด 30 วันบนแผนที่หิมะ → ปลดล็อกหน่วย "นักล่าหิมะ"
- สร้างสิ่งปลูกสร้างครบ 20 ชนิดใน run เดียว → ปลดล็อก Wonder แบบที่ 2
- ตัดไม้ครบ 500 ต้น (สะสม) → ฮีโร่ตัดไม้ได้เร็วขึ้นถาวร
- จบ 100 วันโดยไม่เสียบ้านสักหลัง → ตราและมงกุฎตกแต่ง

### 2.3 ไม่มีสกุลเงินที่สอง
เสนอไม่เพิ่ม "เพชร" หรือสกุลเงินพรีเมียม ในเวอร์ชันนี้ เพื่อความชัดเจน หากภายหลังต้องการ monetization ค่อยพิจารณาแยก

## 3. โครงสร้างอัปเกรด (Ember Tree)

### 3.6 สายตกแต่ง (Cosmetic)
ไม่มีผลต่อเกม ใช้ได้ทั้ง Survival และ PvP
- สีและชุดฮีโร่, สีธงบนฐานแม่, เอฟเฟกต์เก็บคริสตัล, ตราจาก achievement
- เป็นที่ระบายของ Ember สำหรับผู้เล่นที่อัปเกรดเต็มแล้ว

## 4. เพดานและการรีเซ็ต

**[เสนอ]**
- ผลรวมของอัปเกรดตัวเลขในสายฮีโร่และกองทัพต้องไม่เกิน **+50% ดาเมจ / +80% เลือด** เพื่อให้ mutator และ 150 วันยังท้าทาย
- มีปุ่ม **refund** คืน Ember ทั้งหมดของสายใดสายหนึ่ง (จาก Vampire Survivors) เพื่อให้ผู้เล่นทดลอง build นอกเกมได้โดยไม่กลัวเสียแต้ม อาจคิดค่าธรรมเนียม 10%
- **Prestige (ยังไม่ทำในเวอร์ชันแรก)** เมื่อซื้อครบทุกอย่าง ให้รีเซ็ตแลกดาว 1 ดวงที่ปลดล็อก mutator พิเศษและตราถาวร เป็นเนื้อหาสำหรับผู้เล่น 50+ ชั่วโมง

## 5. Mutator (ความยากที่เลือกเอง)

ผู้เล่นเปิดก่อนเริ่ม run เปิดได้หลายตัวพร้อมกัน แต่ละตัวเพิ่มตัวคูณ Ember
| Mutator | ผล | ตัวคูณ |
|---|---|---|
| ศัตรูเร็วขึ้น | +20% ความเร็ว | +0.15 |
| ศัตรูเลือดหนา | +50% เลือด | +0.25 |
| ไม่มีการซ่อม | อาคารซ่อมไม่ได้ | +0.2 |
| ฮีโร่ไม่ฟื้น | ตายแล้วดูเฉยๆ จนจบ wave | +0.3 |
| ทรัพยากรน้อย | แหล่งแร่บนแผนที่ -40% | +0.25 |
| Wave สองทิศตั้งแต่วันแรก | | +0.2 |
| คืนมืด | มองเห็นน้อยลง ไม่มี preview wave | +0.5 |

ใน co-op host เลือก mutator และทุกคนเห็นก่อนกดพร้อม

## 6. วงจรกลับมาเล่น (Retention loop)

| ระยะ | สิ่งที่ดึงกลับมา |
|---|---|
| ทุก run (นาที) | หน้าจบ run แสดง Ember ที่ได้ + แถบความคืบหน้าไปยังอัปเกรดถัดไปที่ผู้เล่น "ปักหมุด" ไว้ + achievement ที่ใกล้สำเร็จ 1–2 อย่าง |
| ทุกวัน | ~~ภารกิจรายวัน~~ **[กำหนด]** ยังไม่ทำในเวอร์ชันแรก (2026-09-08) เก็บไว้เป็นตัวเลือกภายหลังเมื่อมี server-side scheduler |
| ทุกสัปดาห์ | **Seed ประจำสัปดาห์** แผนที่เดียวกันทั้งโลก มีตารางคะแนน โบนัส Ember ครั้งแรก 100 |
| ระยะกลาง (10–30 ชม.) | ปลดล็อกชนิด unit, ธีมแผนที่, ความยาวใหม่ ทีละอย่าง |
| ระยะยาว (30+ ชม.) | Wonder, อาวุธใหม่, mutator ระดับสูง, ตกแต่ง, Prestige |

**[เสนอ]** ทำ "ปักหมุดเป้าหมาย" ตั้งแต่เวอร์ชันแรก เพราะเป็นฟีเจอร์ถูกที่สุดที่ให้ผลมากที่สุด: ผู้เล่นเลือกอัปเกรด 1 อย่างในร้าน แล้วหน้าจบ run ทุกครั้งจะบอกว่าเหลืออีกกี่ Ember

## 7. ความเท่าเทียมใน PvP

**[กำหนด]** PvP ทุกคนเท่ากัน

**[เสนอ]** วิธีทำ
- ตอนเข้าห้อง PvP เกมสร้าง "โปรไฟล์กลาง" ให้ทุกคน: Power 0, Vitality 0, stack ค่ากลาง (เช่น 5), unit และสิ่งปลูกสร้างเปิดครบทุกชนิด, ไม่มี mutator
- ใช้เฉพาะของตกแต่งจากโปรไฟล์จริง
- ห้ามอ่านค่าจาก `profiles` ในการคำนวณใดๆ ของ PvP ให้ engine รับ "ค่าโปรไฟล์" เป็น input แยก เพื่อให้เทสต์ยืนยันได้
