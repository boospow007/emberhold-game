## กติกาของเอกสารในโฟลเดอร์นี้

- ข้อความที่ขึ้นต้นด้วย **[กำหนด]** คือสิ่งที่เจ้าของโปรเจกต์ตัดสินใจแล้ว ห้ามเปลี่ยนโดยไม่ถาม
- ข้อความที่ขึ้นต้นด้วย **[เสนอ]** คือข้อเสนอที่ยังไม่ได้ยืนยัน แก้ไขหรือตัดได้
- ข้อความที่ขึ้นต้นด้วย **[คำถาม]** คือสิ่งที่ต้องตัดสินใจก่อนลงมือทำ
- เมื่อข้อเสนอถูกยืนยัน ให้เปลี่ยนป้ายเป็น [กำหนด] และบันทึกวันที่
